PDF Metadata Viewer

Read document metadata locally. Designed for quick, private work directly on this device.

Drag & drop a PDF here

Files are processed locally when browser support allows. Maximum 100 MB per file.

    Need to reduce a file’s size? Try Compress PDF. Your selected files stay in this browser session.

    Questions about PDF Metadata Viewer

    Is PDF Metadata Viewer free to use?

    Yes. There is no account requirement.

    Are my files uploaded?

    This tool processes files in your browser. No file is sent to a WYPDF server.

    Can I use it on mobile?

    Yes, provided your mobile browser supports the file type and available memory.
